# خطة الاختبار عند وصول PS4 — Firmware 14.00 / GoldHEN
**الحالة:** جاهزة للتنفيذ لاحقًا، **لم تُنفذ على جهاز حقيقي**. التاريخ: 9 نوفمبر 2026.

## مصدر إصدار GoldHEN وخط التوقف
- المطور SiSTR0 أعلن **GoldHEN v2.4b18.13 (Beta)** وإضافة دعم FW 14.00 وإصلاح FTP SIZE: https://ko-fi.com/s/e694c36022
- رابط المشروع الأساسي: https://github.com/GoldHEN/GoldHEN
- **Developer-claimed support ≠ اختبار هذا التطبيق على FW14**. تحتاج طريقة تحميل/استغلال مناسبة ومتحققًا منها للجهاز نفسه؛ لا نعتمد موقع Host عشوائيًا ولا نعد بنجاح 100%.
- **STOP:** إن كان Firmware الجهاز مختلفًا، أو لم تعمل GoldHEN، أو لم يظهر إصدارها الحقيقي، لا نجرب تطبيقنا ولا نحدث النظام آليًا. Firmware 14.02 ليس 14.00.
- لا تثبّت أي System Update ولا تفعّل تحديث النظام تلقائيًا أثناء التجربة، وخذ نسخة احتياطية من Save Data المهمة قبل البدء.

## 1. تجهيز الجهاز وتأكيد البيئة (قبل PKG)
1. صوّر **Settings → System → System Information** واحفظ رقم Firmware الفعلي، وموديل PS4.
2. من مصدر المطوّر الموثوق، استخدم إصدار GoldHEN المثبت أنه يدعم **نفس Firmware**. بعد التفعيل افتح قائمة GoldHEN والتقط رقم نسختها. لا تعتبر إغلاق Issue GitHub وحده إثبات نجاح.
3. افحص أن **GoldHEN FTP Server** يعمل محليًا على المنفذ **2121** إذا كان هناك خيار تفعيله. لا تفتح المنفذ للإنترنت العام. إن لم يعمل، توقف وسجل المشكلة بدل التجربة بكتابة ملفات النظام.
4. اختر لعبة منزلية/مملوكة أو Homebrew مثبتة بالفعل، ويُفضّل أن تكون بيانات CUSA و`icon0.png` متاحة؛ لا تثبّت تحديث لعبة ولا تعدل ملفات اللعبة لغرض الفحص.

**معيار الانتقال:** رقم FW مؤكد، GoldHEN فعالة، FTP متاح، لعبة اختبار معروفة. إن غاب أي شرط فلا ننتقل إلى فحص الخلفية.

## 2. أول تجربة آمنة للتطبيق (الوضع الافتراضي READ ONLY)
1. نجهز **PKG جديد من نفس Commit المراد اختباره** باستخدام OpenOrbis بعد نجاح Host Tests والبناء. لا تستخدم PKG v01.14 القديم أو إعادة تسمية ملف قديم. قبل التجربة، نتحقق من هوية PKG ومصدره وأنه تطبيق Homebrew منفصل.
2. ثبت التطبيق بالطريقة التي يوفرها GoldHEN على الجهاز، وشغّله **مع بقاء Download وInstall داخل التطبيق معطّلين**.
3. تأكد من فتح Home، ظهور اللعبة باسمها/ CUSA/الأيقونة المحلية إن توفرت، والتنقل R1/L1 عبر الأقسام الثمانية، وعودة Settings + R1 إلى Home.
4. افتح Details ثم Downloads ثم ارجع إلى Home. اختبر Circle/Options والبحث. تحقق أن الرسائل لا تدّعي تحديثًا أو تثبيتًا غير مثبت.
5. سجّل: هل يوجد تعطل/تجميد/خروج بطيء؟ هل تتأثر أي بيانات محفوظة؟ التقط صورًا للشاشات وسجل التشخيص إن توفر.

**معيار الانتقال:** التطبيق مستقر، يخرج طبيعيًا، ولا يغيّر الألعاب/الحفظ. إذا تعطل، **STOP** ولا تختبر ملفات الفن العريضة.

## 3. فحص وجود pic1.png اختياري (فقط بعد النجاح السابق)
هذا فحص **وجود اسم ملف** وليس قراءة/تحميل ملف أو التحقق من سلامته.

1. نبني PKG تشخيصيًا *مختلفًا* مع خيار الترجمة `PS4_ENABLE_EXPERIMENTAL_WIDE_ART_PROBE`، بعد مراجعة الكود ونجاح Host + OpenOrbis. الخيار **OFF** في نسخة الإنتاج.
2. يشغّل الفحص اتصال FTP محليًا **مستقلًا**، ويطلب `LIST /user/appmeta/CUSAxxxxx` فقط لأول عنوان أساسي تم التحقق من معرفه. لا يستخدم `RETR` ولا `STOR` ولا `DELETE` ولا يحاول تثبيت PKG.
3. احفظ السجل كما هو، وابحث عن:
   - `WIDE_ART_LIST_RC`: نتيجة طلب القراءة.
   - `WIDE_ART_PIC1_LISTED`: تظهر فقط عندما يكتمل LIST بنجاح. القيمة `1` تعني أن **اسم** `pic1.png` شوهد في السرد، **ولا تعني** أنه قابل للقراءة أو أن الصورة سليمة.
   - `WIDE_ART_CONNECT_FAILED` أو `WIDE_ART_GREETING_FAILED`: فشل الاتصال؛ لا نستنتج أن الملف غير موجود.
4. إن لم يوجد الملف أو فشل LIST، نلتزم بخلفية `icon0.png` الحالية. لا نخمن مسارًا بديلًا ونفعّله في الإنتاج دون دليل مستقل.

**معيار الانتقال إلى قراءة صورة فعلية مستقبلًا:** توثيق المسار والصلاحيات من الجهاز، فحص `SIZE` أو طريقة قياس موثوقة، حدود حازمة للحجم والأبعاد وCRC، اختبار صور PNG تالفة، ثم Lazy Read-only fetch مع Cancellation وFallback. لا يتم كل هذا بمجرد نجاح LIST.

## أدلة قبول يجب الاحتفاظ بها
- صورة Firmware، صورة GoldHEN/version، حالة GoldHEN FTP، لقطة Home وDetails وDownloads، عنوان CUSA التجريبي، سجلات الفحص، SHA الـCommit ورابط CI، وتوثيق التعطل إن حدث.
- **النتيجة الممكنة:** PASS / FAIL / NOT TESTED لكل نقطة. لا تُحوّل NOT TESTED إلى PASS.
- **ممنوع حاليًا:** تنزيل تحديثات الألعاب، تثبيت Retail/FPKG، تعديل الملفات أو استبدال ملفات النظام، الادعاء بالتوافق المطلق.

**مرجع التنفيذ:** `ps4/src/ftp_scanner_v05.c` و`ps4/src/ui_local_art_probe.h`. الفحص `PS4_ENABLE_EXPERIMENTAL_WIDE_ART_PROBE` مغلق افتراضيًا؛ ما ثبت حاليًا هو Host + OpenOrbis Build فقط، **وليس PS4 FW14**.
