# PS4 Auto Updater — مشروع تجريبي

مشروع لتجهيز تطبيق PS4 يكتشف ألعاب الجهاز ويقارن بياناتها مع تحديثات متوافقة موثّقة. **ليس متجر تحديثات جاهزًا بعد.**

## حالة المشروع

- **النسخة التي يجري بناؤها:** ماسح FTP المحلي v0.5.2 (إصدار الحزمة `01.07`، Title ID: `BREW00197`).
- **البناء والاختبارات:** تُنفذ تلقائيًا على GitHub Actions باستخدام OpenOrbis.
- **الاختبار على جهاز PS4:** لم يُتحقق بعد من اتصال FTP الذاتي أو عمل النسخة الحالية على نظام 14.00.
- **تحديثات FPKG:** لا يوجد فهرس عام موثّق لتحديثات جميع الألعاب. لم نفعّل التحميل أو التثبيت.
- **التقرير الموجود في الموقع:** مصدره جرد تاريخي وليس مسحًا مباشرًا لألعاب الجهاز.

## كيف تعمل نسخة الماسح التجريبية؟

1. تتصل محليًا فقط بـ `127.0.0.1:2121` (خادم GoldHEN FTP إذا كان مفعّلًا)، وتحاول أوامر القراءة بدون تسجيل دخول أولًا وتستخدم `USER anonymous` فقط إذا رد الخادم بـ `530`.
2. تستخدم أوامر قراءة FTP فقط: `USER` و`PASS` و`TYPE` و`PASV` و`LIST` و`RETR` و`QUIT`.
3. تستخرج المعلومات من `param.sfo`، وتستبعد العناصر غير المصنفة كألعاب وتمنع التكرار.
4. تحاول تأكيد التثبيت عبر `AppInstUtil`، وتضع `UNKNOWN` عند عدم القدرة على التحقق.
5. تحفظ نتائج محلية دون تعديل ملفات الألعاب.

**الملفات الناتجة على السوني (وليس على GitHub):**
- `/data/PS4AutoUpdater/diagnostic_v05.txt`
- `/data/PS4AutoUpdater/inventory_v05.json`

إذا كانت `scan_complete=false`، فلا تعتبر قائمة الألعاب شاملة، حتى لو احتوت بعض العناوين. كذلك `metadata_only=true` تعني أن العثور على ملفات metadata لا يثبت وجود اللعبة مثبتة.

## رابط البناء

[PS4 Native Scanner Build (Experimental)](https://github.com/obsp081-coder/ps4-updates/actions/workflows/ps4-build.yml)

عند نجاح البناء تُنشر حزمة `ps4-scanner-experimental` كـArtifact. نجاح GitHub Actions يثبت نجاح تجميع الكود والاختبارات الوهمية فقط، **ولا يثبت التوافق مع السوني**.

## حدود الأمان والخصوصية

- يمنع الماسح تنزيل أو تثبيت أو حذف الألعاب أو التحديثات.
- يستقبل اتصال FTP من المضيف المحلي فقط ولا يتبع عنوانًا خارجيًا من استجابة PASV.
- لا ترفع ملف `inventory_v05.json` إلى مستودع GitHub العام؛ قد يحتوي أسماء ألعاب ومعرّفات Content ID.
- لا تثبّت تحديثات عشوائية اعتمادًا على CUSA وحده. يلزم التحقق من Content ID وإصدار الأساس وإصدار النظام ونوع الحزمة وتوافقها مع FPKG.
