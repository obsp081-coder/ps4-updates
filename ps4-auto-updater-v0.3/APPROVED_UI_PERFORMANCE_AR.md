# مواصفات الواجهة المعتمدة — الأزرق الملكي والأداء الخفيف

الحالة: **DESIGN APPROVED / NOT FULLY IMPLEMENTED OR TESTED**. الصور التخيلية توضح الشكل فقط؛ أي حجم/تحديث/نتيجة توافق في الصور غير حقيقي حتى يُقرأ من الجهاز ومصدر مرخص.

## الشاشات المعتمدة

- تطبيق PS4 Native، Dark Mode بالأزرق الملكي والأسود مع إضاءة سماوية خفيفة وألوان مبدئية #061126 و#0C244A و#116BCE و#37ADFF و#EAF4FF.
- واجهة عربية كاملة RTL مع الحفاظ على أسماء الألعاب وCUSA التي يخرجها النظام بلغتها.
- **الرئيسية**: إحصائيات موجزة، آخر التحديثات والتنزيلات، قائمة متوسطة من 5–6 ألعاب ظاهرة بالصورة المحلية والاسم والإصدار والحجم (عند توفره)، ولوحة تفاصيل جانبية مختصرة.
- **صفحة اللعبة الكاملة**: صورة اللعبة، CUSA والمنطقة والحجم والنسخة ونوع اللعبة Retail أو FPKG بعد التحقق، Firmware المطلوب والإصدارات المتاحة وأسباب رفض غير المتوافق، بدون بيانات مصطنعة.
- **صفحة التنزيلات**: الطابور والحالة الفعلية والسرعة والحجم والتقدم، وإيقاف مؤقت واستكمال/إلغاء فقط حيث يسمح المصدر. تزامن التنزيلات يُفعّل بعد قياس أثره على PS4؛ البداية بتنزيل واحد.
- **الخلفية**: صورة محلية من اللعبة المختارة محوّلة إلى دقة منخفضة ومموهة مرة عند تغيير التحديد، مع طبقة داكنة تضمن قراءة النص، لا تمويه مباشر كامل الدقة كل Frame.
- حركة تركيز خفيفة وسريعة، لا أصوات عند التنقل، تنبيه صوتي فقط للنجاح أو الفشل إذا ثبت مسار الصوت. البحث بالاسم أو CUSA فقط.
- التثبيت التلقائي بعد التنزيل لا يُفعل إلا بموافقة مسبقة صريحة وبعد إثبات التوافق ومصدر مصرح به وواجهة تثبيت آمنة على FW14.

## الأداء شرط قبول — الأرقام التالية أهداف مقترحة لا نتائج قياس

1. لا WebView ولا Game Engine ثقيل؛ تطوير Native بتبعيات قليلة قدر الإمكان.
2. تجنب إعادة رسم المشهد بالكامل في السكون؛ تحديث عند التغيير فقط. استهدف 30 FPS على Base PS4 أثناء التنقل **بعد قياس الجهاز الحقيقي**.
3. صور الألعاب: Decode خارج render loop، Cache LRU محدود 8–16 صورة مصغرة حجم 256×256 لكل صورة، وخلفية وحيدة منخفضة الدقة، مع حدود صريحة لأبعاد وفك ضغط الصور.
4. استهدف أقل من 64 MiB لأصول الواجهة فوق Framebuffers، **ميزانية استرشادية تحتاج Hardware profiling**؛ تخفيض تدريجي إذا ارتفع استهلاك الذاكرة.
5. فحص الشبكة/الملفات في عملية غير معطِّلة للواجهة مع Timeouts وCancel؛ شاشة Progress من بيانات فعلية لا Mock.
6. استهدف ظهور واجهة أولية خلال ثانيتين على جهاز PS4 أساسي بعد تحسين الإقلاع، وليس ضمانًا حتى القياس.
7. دعم UTF-8 وArabic shaping وRTL وخط مرخّص؛ خط Scanner الحالي لا يقدم العربية بصورة صحيحة.
8. لا تحرّر VideoOut buffers بعد رجوع RESOURCE_BUSY ‏0x80290009؛ حافظ على مسار SystemService shell exit الذي اجتاز اختبار المستخدم.
9. تحكّم بالتخزين الداخلي قبل التنزيل مع تنظيف مؤقتات مُحددة، وعدم حذف الألعاب أو ملفات الحفظ.
10. إذا تعذر الحصول على صورة أو حجم أو إصدار متوافق، اعرض Placeholder أو غير متوفر؛ لا تختلق بيانات.

## اختبارات قبول قبل أي PKG نهائي

- 5–6 صفوف تعمل، خلفية اللعبة تتغير دون تجمد، البحث وفتح وإغلاق صفحة التفاصيل.
- قياسات RAM وFrame time وفتح/إغلاق 100 مرة على جهاز PS4 14.00 الحقيقي، وأحمال 0/1/50/256 لعبة وملفات PNG فاسدة.
- اختبار تشغيل واجهة أثناء FTP/HTTP بطيء، واختبارات Full disk/No network/Cancel/Resume.
- ممنوع إعلان Install متاحًا دون إثبات Retail/FPKG وتطابق CUSA وContent ID ونسخة Base/Firmware، ومصدر مخول، وآلية تثبيت مجرّبة على الجهاز.
- قرار المستخدم: **لا تسليم PKG بوصفه البرنامج النهائي حتى اكتمال الوظائف والفحوص.**
